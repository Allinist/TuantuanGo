# TuantuanGo 设计与开发文档

TuantuanGo 是一个面向微信小程序的开团/拼团交易工具。首期以“出谷子/文创”分类为核心场景，服务两类角色：

- 买家：默认入口，浏览市场、搜索筛选团购、进入开团页面、选择商品、加入购物车、下单并上传支付截图，查看物流、合并发货、转单和评价团长。
- 团长：创建团、批量上架商品与库存、配置销售组合规则、上传收款二维码、管理库存、审核订单、填写物流单号、处理合并发货和转单。

## 首期范围

首期建议聚焦以下能力：

1. 买家市场首页、分类、搜索、筛选。
2. 团详情页和商品选择页。
3. 批量商品上架，以及直出、捆出、自选、打包直出、直接团购等销售组合。
4. 购物车、库存预占/扣减、库存不足提示。
5. 订单确认、上传支付截图、团长人工审核。
6. 团长开团、商品管理、销售组合管理、收款二维码管理。
7. 订单物流单号、物流追踪、合并发货和转单记录。

## 后续扩展方向

- 开屏广告、嵌入式广告、付费免广告。
- 自动支付或半自动收款截图识别。
- 信用体系、团长评分与评价、买家黑名单和付费黑名单能力。
- 物流单号、合并发货、转单市场。
- 多分类市场，如手作、二手、票务、同城取货。
