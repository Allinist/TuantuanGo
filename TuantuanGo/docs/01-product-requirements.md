# 产品需求说明

## 1. 产品定位

TuantuanGo 是一个微信小程序开团/拼团平台，帮助团长快速发布商品团，帮助买家在市场中查找、购买、拼单、确认订单。首期重点服务“谷子/文创”交易场景，包括直出、捆出、自选、多人成团等常见规则。

平台第一阶段不直接托管支付资金，采用“团长上传收款二维码，买家支付后上传截图，团长人工审核”的模式。后续可扩展支付接口、广告盈利、付费免广告等能力。

## 2. 用户角色

### 2.1 买家

买家是小程序默认入口用户。

核心能力：

- 浏览市场中已有开团和销售。
- 按分类、关键词、价格、团状态、发货方式、包邮条件等筛选。
- 点击小程序卡片进入对应开团购买页面。
- 查看团详情、商品规则、团长说明、库存、收款二维码。
- 选择商品加入购物车。
- 提交订单并上传支付截图。
- 查看物流单号、物流轨迹和发货状态。
- 在订单确认后追加商品、申请合并发货、转单给其他买家。
- 完成购买后对团长进行评分和评价。

限制：

- 订单被团长确认后，不允许买家取消订单。
- 订单被团长确认后，不允许删除已购物品。
- 可追加商品，但追加商品应生成追加明细并重新进入待支付/待审核流程。
- 未购买或订单未确认/完成的用户不能评价团长。

### 2.2 团长

团长负责创建和维护团。

核心能力：

- 创建单人团或多人拼团。
- 选择商品分类，如出谷子/文创。
- 一次增加 N 款商品，批量配置商品信息、库存、图片、价格、描述。
- 配置销售规则：打包直出、捆、被捆、直接团购、直出、自选。
- 根据商品上架模式生成不同销售组合，包括组合内商品、组合库存、价格和购买限制。
- 配置邮费、包邮、打包费、物料费、小费等费用项。
- 上传固定展示的收款二维码。
- 审核买家支付截图。
- 管理订单、库存、发货、物流单号、合并发货、转单。
- 对同款多数量商品配置编号标记，方便买家确认对应实物。

限制：

- 团长应明确开团规则，发布后影响已下单买家的核心规则不应随意修改。
- 已被确认下单的商品库存不应被其他订单重复占用。
- 已进入销售组合并产生订单的商品，不应随意修改组合关系；若必须调整，应只影响后续新订单。

## 3. 核心页面

### 3.1 买家市场首页

首页是买家主入口。

主页底部采用固定 tab 结构：

- 市场：默认首页，展示开团市场、分类、搜索和筛选。
- 购物车：展示买家按团隔离的购物车。
- 中间加号：位于“购物车”和“订单”之间，不作为独立 tab，点击后跳转至卖家/团长上架商品、开团页面。
- 订单：展示买家的订单列表、订单状态和订单详情入口。
- 设置：展示账号资料、角色状态、通知、免广告权益和基础设置。

中间加号是团长创建内容的快捷入口。未具备团长权限的用户点击时，应先进入团长身份申请或授权说明；已具备团长权限的用户点击时，默认进入开团页面，并可继续上架商品、配置销售规则、库存、收款二维码和发车条件。

需要展示：

- 顶部搜索框。
- 分类入口，首期分类为“出谷子/文创”。
- 筛选入口：价格区间、销售规则、团状态、包邮、发车条件、发布时间。
- 团列表卡片：主图、标题、团长昵称、分类、最低价/价格区间、剩余库存、团状态、规则标签。
- 广告位预留：开屏广告、列表嵌入广告、详情页广告。

点击团卡片后进入团详情页。

### 3.2 团详情页

需要展示：

- 团标题、简介、分类、团长信息。
- 团类型：单人团或多人拼团。
- 团状态：草稿、进行中、已发车、已截团、已完成、已取消。
- 销售规则摘要。
- 发车条件，若为多人拼团则必须展示。
- 收款二维码固定展示区域。
- 商品入口：直出商品、捆出首页、自选商品列表。
- 销售组合入口：展示打包直出组合、捆出组合、直接团购商品组。
- 买家购物车入口。
- 下单按钮。

### 3.3 团长批量上架与销售组合页

团长/卖家在开团时需要支持一次增加 N 款商品，并为每款商品录入对应库存。

需要支持：

- 批量新增商品行：商品名、图片、描述、单价、库存、限购、排序。
- 批量导入库存：普通数量库存或同款编号库存。
- 批量编辑：统一设置分类、邮费、包邮、打包费、物料费、小费。
- 单品模式选择：打包直出、捆、被捆、直接团购、普通直出、普通自选。
- 组合生成预览：根据选择的模式生成可售组合，并展示组合商品、组合库存、组合价和购买限制。
- 组合库存校验：组合库存不得超过组合内任一商品可售库存。
- 发布前校验：缺少价格、库存、图片或必要组合关系时，提示团长补全。

上架模式说明：

- 打包直出：多个商品作为一个固定包出售，买家购买时一次加入整包商品，组合库存由包内商品库存共同决定。
- 捆：作为主商品出售，买家购买时必须搭配被捆商品；可配置指定捆金额或固定被捆组合。
- 被捆：不能单独作为主商品购买，默认只出现在捆出规则的被捆选择或固定捆组合中。
- 直接团购：商品直接参与团购，可按单人团或多人拼团规则展示库存、价格、发车条件。
- 普通直出：商品可单独直接购买，不要求搭配其他商品。
- 普通自选：商品进入自选池，买家可自由组合购买。

销售组合发布后，买家侧商品选择页按照组合类型展示，不需要理解团长批量录入过程。

### 3.4 商品选择页

不同模式有不同页面结构。

直出：

- 直接展示可购买商品。
- 显示商品价格、库存、邮费或包邮信息。
- 买家选择数量后加入购物车。
- 同款商品存在多个实物时，可展示团长/卖家配置的编号标记，如 A1、A2、拍照位置号或瑕疵编号，买家可按编号选择或查看对应商品。

打包直出：

- 展示固定包内商品清单、包价、包库存和包内商品明细。
- 买家购买时整包加入购物车，不允许拆开选择。
- 若包内任一商品库存不足，整包不可购买。

捆出：

- 第一页展示主商品和捆绑规则。
- 若为“指定捆多少钱”模式，第二页展示可选被捆商品列表，买家选择被捆商品，金额可超过要求。
- 若为“固定捆物品”模式，第二页直接展示固定捆物表单，买家确认后加入购物车。

自选：

- 无捆绑要求。
- 商品选择页直接展示所有可选商品。
- 可配置满额包邮、打包费、物料费、小费等费用项。

直接团购：

- 展示商品团购价、库存、单人团/多人拼团状态。
- 若为多人拼团，应展示发车条件和当前进度。
- 买家按商品数量加入购物车或直接提交订单。

### 3.5 购物车页

需要展示：

- 已选商品列表。
- 商品规则来源，如直出/捆出/自选。
- 销售组合来源，如打包直出/捆/被捆/直接团购。
- 数量、单价、小计。
- 邮费、打包费、物料费、小费等费用。
- 库存状态提示。
- 提交订单按钮。

提交时进行库存校验和库存扣减/预占。

### 3.6 确认订单页

需要展示：

- 商品明细。
- 费用明细。
- 应付金额。
- 收款二维码。
- 支付截图上传控件。
- 买家备注。
- 确认提交按钮。

提交后进入待团长审核状态。

### 3.7 订单详情与物流页

需要展示：

- 订单状态、支付审核状态、发货状态。
- 物流公司、物流单号、复制单号入口。
- 物流轨迹列表，包括揽收、运输、派送、签收等节点。
- 合并发货信息，若订单被合并，应展示合并发货单和关联订单。
- 转单记录，展示原买家、接收人、转单状态和历史记录。
- 确认收货入口。
- 符合条件时展示评价入口。

### 3.8 团长管理页

需要展示：

- 我创建的团列表。
- 创建新团入口。
- 团数据概览：浏览量、购物车数、待审核订单、已确认订单、库存占用。
- 订单审核入口。
- 收款二维码管理。
- 商品和库存管理。
- 批量上架商品入口。
- 销售组合管理入口。
- 物流单号填写和批量发货入口。
- 合并发货处理入口。
- 转单记录查看和确认入口。
- 团长评分、评价列表和评价回复入口。

团长管理能力可以从中间加号入口进入，也可以在设置页中保留“团长工作台”辅助入口。买家主路径仍以市场、购物车、订单为核心，不让团长入口占用市场首页主视觉。

### 3.9 黑名单与评价治理

后续应提供黑名单能力：

- 团长可将恶意下单、长期占库存、拒付或频繁纠纷用户加入黑名单。
- 黑名单用户进入对应团长的团时，应限制下单、转单接收和评价。
- 黑名单可先作为基础治理能力预留，后续可扩展为付费能力，如高级黑名单数量、跨团同步、备注标签和导入导出。

团长评分与评价规则：

- 仅购买过且订单达到 confirmed、shipped 或 completed 状态的买家可以评价。
- 同一订单只能评价一次；追加商品可复用原订单评价或生成追加评价，需二选一保持规则稳定。
- 评价内容、图片和团长回复必须接入违禁内容审核。
- 审核未通过的评价不应公开展示，可提示用户修改后重新提交。
- 团长评分应聚合展示在团详情、团长资料和市场卡片中。

## 4. 权限边界

- 未登录用户可浏览市场和团详情，但下单前必须完成微信授权登录。
- 买家只能管理自己的购物车和订单。
- 团长只能管理自己创建的团。
- 管理员可处理违规团、投诉、广告配置和平台分类。

## 5. 广告与付费预留

首期可只保留数据结构和 UI 插槽，不接入真实广告。

建议预留：

- 开屏广告：进入小程序时展示。
- 市场列表广告：按固定间隔插入广告卡片。
- 团详情广告：商品区或订单确认前展示。
- 付费免广告：用户购买会员后隐藏广告。

广告应避免遮挡下单、上传支付截图、订单确认等关键交易路径。
